Interlace

Offline archive. No account. No sync. This window never phones home.

Interlace never phones home and contains no HTTP client capable of doing so. The archive is a folder on this Mac. Phase 1 CLI still lives in the terminal (cargo install interlace). This app is the Phase 2 shell — import, search, and timelines land in the next PRs.

Not encrypted at rest. The folder is the backup unit. Use FileVault.
